# 本包提交约束

来源：用户补充的参赛包 README 与公告。包编号 `pkg-08e82c8d`，发放时间 `2026-09-22 10:56:20`。公告通用示例省略了包编号，但本包明确要求携带，因此输出保留包编号。

比赛目标是将自然语言资产需求转换为正确的 FOFA Query。允许 Agent、Skill、模型、规则或任意组合，只根据最终答案评分，不要求提交系统。

- 使用 UTF-8 JSON，允许 BOM；不是 JSONL，文件不超过8 MB。
- 顶层为 `选手名称`、`参赛包编号`、`答案`。
- 每题只含 `题号`、`查询语句`，保留本包全部题号；缺题、重复、未知题号或数量不一致会导致整份答卷拒绝。
- 能转换时只提交一条最终合法完整 Query，无解释、候选答案或 Markdown。
- 不能直接转换时只能填写：`该需求不能直接转换为FOFA搜索语句`。不能填写 null、空串或自定义说明。
- 本包没有参考答案；平台按查询实际执行结果评分。
- 不包含账号、密钥或未经授权的数据；是否允许重复提交以比赛网站为准。

Go 是用户指定的项目语言，不是比赛公告限制。本仓库包含代码与答卷；上传 GitHub 不等于上传比赛网站。
