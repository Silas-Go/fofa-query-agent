# T1 模块交接与反例

## 1. 独立验收的共同条件结构

以下是交接契约，不是 FOFA 语法，也不要求采用特定编程语言。字段名使用语义名称，T2 再映射到平台字段。

每题内部结果包含：题号、任务类型、条件、原文依据、采用的解释编号、待核实能力、外部证据、问题列表。最终输出仍只使用 contract.md 定义的六个字段。

条件节点固定为六类：

| 节点 | 内容 | 约束 |
|---|---|---|
| all | 子条件列表 | 全部成立；至少两项 |
| any | 子条件列表 | 任一成立；至少两项 |
| not | 一个子条件 | 明确逻辑否定；不能默认把缺失值当某种布尔值 |
| predicate | 语义字段、操作、值 | 字段例：资产IP、网页标题、证书颁发者组织；字段及操作是否合法由 T2 字典约束 |
| at_least | 最少数量、子条件列表 | 数量为整数且在 1 至子条件数之间；按不同条件计数 |
| same_object | 对象范围、子条件 | 要求同一个嵌套对象满足全部条件，用于 M087；不能展平成任意对象的独立命中 |

原子操作至少覆盖：精确等于、包含、后缀、为空、非空、属于集合、属于网段、闭区间、严格大于、严格小于、域名根域关系、域名标签模式。排除可用 not 包装；不把“不包含”擅自附加“非空”。尚未确定的材料不进入假值节点，而是保留问题或依赖。

值类型：端口、ASN 和数量用整数；布尔标记用布尔值；IP/CIDR、日期、版本、指纹、字面文本用字符串；集合与区间用有序列表。证书序列号使用“进制 + 数字字符串”，禁止浮点数。字段比较（如 M047）保留双方语义，不能伪装成普通字符串值。

每个叶子保存能够在原题中找到的原文片段；归一化值另存，不改原文。外部派生字段保存证据引用。M096 的实际字段不要求在题目里直接出现。

最小例子：M013 的根节点是 all，子节点分别是标题/正文的 any、国家排除、更新时间严格大于。M081 的根节点是 all，子节点为 Grafana 和四项中至少两项非空。

职责约束：T3 解析条件和候选问题；T2 提供字段能力证据；T4 根据统一规则决定最终状态并生成查询。T5 只提供源查询/材料的等价条件和证据，不能绕过 T4。

## 3. T2 需要核实并冻结的内容

逐题具体核实项已列入 acceptance.json。优先处理以下会改变可实现性的项目：

1. 精确、包含、空值、非空、否定及字段缺失时的真实语义；时间比较的精度和时区。
2. 域名标签边界、单字符匹配、根域、CNAME 根域，以及访问域名与 URL 路径的区分。
3. 协议、传输协议、产品、门类、云厂商与云服务类别的枚举；地域尤其大陆与港澳台的映射。
4. 证书主体/颁发者字段、未过期/有效/匹配的定义；M047 是否支持题意中的比较。
5. M083/M086 的源平台字段语义，M087 的嵌套对象约束能否等价保留。
6. 图标哈希算法及输入编码；M100 序列号进制、大小写、前导零和查询格式。

能力字典每项至少记录：语义概念、目标字段、支持操作、值类型、空值语义、来源、核对日期、验证方式和结果。来源必须来自官方材料或真实验证；没有依据的映射不能冻结为支持。

能力核实失败不自动改题。若证实平台不支持，修订预期状态时同时记录受影响题号、不可保留的条件及证据。未查证完的项目记为待核实，不进入已通过计数。

## 4. T5 固定材料的要求

- M096 保存所读章节的必要片段或派生字段清单、URL、获取日期和摘要；本次已核对的四字段见 contract.md。
- M097 保存页面选图依据、最终图标 URL、图标字节摘要和计算记录；正确哈希绑定具体图标快照，不绑定永久不变的网址。T1 未下载图标或计算哈希。
- M099 使用官方公告中的产品事实；FOFA 产品枚举由 T2 确认。
- M100 已可确定数值：十六进制 `63BD83716214836EF80075356161EB06` = 十进制 `132577581667764526475870473477991557894`。这个等值关系不代表 FOFA 已确认使用十进制查询。

## 5. 输出示例的使用范围

output.examples.json 展示六种状态，不是本批次完整答案。其中 M097 是人为设定的下载超时故障示例，不能声称真实网站发生了超时。

output.schema.json 约束单条结构和状态/查询关系。它不验证查询语义、题号唯一、记录顺序或原文保真；这些必须对照输入单独检查。日期 format 需要验证器开启格式检查。端口的协议数值边界含0，但平台是否接受查询0仍归 T2 验证。

## 6. T1 完成条件

- 原题原样保存，100题逐题对应，无重号或遗漏。
- 六种状态、输出约束、歧义解释和计分规则可执行。
- 每题具有必需条件、禁止事项、预期状态及能力核实项。
- 代表性正反例覆盖逻辑、范围、空值、转义、异常和外部依赖。
- 明确区分“语义规则已制定”“能力待核实”“查询未执行”，不以文档完成冒充系统完成。
